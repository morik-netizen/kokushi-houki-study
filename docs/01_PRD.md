# PRD: 関係法規マスター（柔道整復師国試学習アプリ）

## 概要

柔道整復師国家試験の「関係法規」科目（過去34年分393問）を、学生が100%正解できるようにする学習アプリ。

## 背景・課題

- 関係法規は暗記科目だが、類似概念の混同や忘却により得点が安定しない
- 紙ベースの問題集では「間違えた問題の繰り返し」が非効率
- 学生個別の弱点を把握し、最適な復習タイミングを提供する仕組みがない

## ターゲットユーザー

| 属性 | 詳細 |
|------|------|
| 対象 | 柔道整復学科の学生（前期） |
| 年齢層 | 10代後半〜20代前半が中心 |
| 利用端末 | スマートフォン・タブレット中心 |

## 授業情報（サンプル）

| 項目 | 詳細 |
|------|------|
| 科目名 | 関係法規 |
| 授業回数 | 15回（うち第15回は終講試験） |
| 第1回 | 前期初週 |
| 最終回 | 前期最終週（終講試験） |

> 実際の授業日程・担当教員情報は各教育機関のものに差し替えてください。

## 成功指標

| KPI | 目標値 |
|-----|--------|
| DAU/MAU比率 | 40%以上 |
| 2日目継続率 | 70%以上 |
| 7日目継続率 | 50%以上 |
| 平均セッション長 | 5-8分 |
| 練習テスト合格率(80%) | 全学生の80%以上 |
| 全問カバー率 | 全学生が100% |

## 最終ゴール

終講試験および国家試験の関係法規セクションの得点向上。
